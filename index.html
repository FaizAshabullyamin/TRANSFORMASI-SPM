Nota Ringkas & Formula Transformasi SPM

1. Translasi

Format Vektor (x / y): x = pergerakan mengufuk (kanan: +, kiri: -), y = pergerakan menegak (atas: +, bawah: -).

2. Pantulan

Mesti nyatakan garis pantulan: x = c (garis menegak), y = c (garis mengufuk), atau y = x / y = -x.

3. Pembesaran

Faktor Skala (k): Panjang Sisi Imej / Panjang Sisi Objek.
Pusat Pembesaran (x, y): Titik persilangan 2 garis lurus yang dibina antara bucu sepadan.

4. Putaran

Mesti nyatakan: (1) Sudut (90° / 180°), (2) Arah (Ikut / Lawan Jam - jika 90°), (3) Pusat Putaran (x, y) daripada pembahagi dua sama serenjang.

Tetapan Simpanan Data Google Sheet

Kod Google Apps Script:

Buka Google Sheet > Extensions > Apps Script > Tampal kod di bawah > Deploy as Web App (Anyone):

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), data.namaPelajar || data.name, data.sekolah || data.school, data.markah || data.score, data.jumlahSoalan || data.qIndex]);
  return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var data = [];
  for (var i = 1; i < rows.length; i++) {
    if (rows[i][1]) {
      data.push({
        name: rows[i][1],
        school: rows[i][2],
        score: Number(rows[i][3]) || 0,
        qCount: Number(rows[i][4]) || 0
      });
    }
  }
  return ContentService.createTextOutput(JSON.stringify(data)).setMimeType(ContentService.MimeType.JSON);
}
